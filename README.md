# Тренажёры: пишем печатными буквами

Готовые прописи в формате Word (.docx) — скачайте, распечатайте и пишите ручкой или карандашом.

| Файл | Что внутри | Страниц |
|---|---|---|
| [01_Заглавные_печатные_буквы.docx](тренажеры/01_Заглавные_печатные_буквы.docx) | Все 33 заглавные буквы: образец, обводка, самостоятельное письмо и порядок написания каждой буквы | 12 |
| [02_Строчные_печатные_буквы.docx](тренажеры/02_Строчные_печатные_буквы.docx) | Все 33 строчные буквы с подсказками, чем они отличаются от заглавных | 12 |
| [03_Слоги_и_слова.docx](тренажеры/03_Слоги_и_слова.docx) | Пары «Аа», слоги, слова и имена | 5 |
| [04_Цифры_и_предложения.docx](тренажеры/04_Цифры_и_предложения.docx) | Цифры 0–9 и предложения (в том числе со всеми буквами алфавита) | 3 |
| [05_Заполнение_бланков.docx](тренажеры/05_Заполнение_бланков.docx) | Письмо в клеточках, как в анкетах: образец анкеты, поля для своих данных, сетка для тренировки | 4 |

## Как скачать

Откройте нужный файл по ссылке выше и нажмите кнопку **Download** (значок со стрелкой вниз справа).
Чтобы скачать всё сразу: на главной странице репозитория **Code → Download ZIP**.

## Порядок занятий

1. Тренажёр 1 — заглавные буквы (по 3 буквы в день).
2. Тренажёр 2 — строчные буквы.
3. Тренажёр 3 — слоги и слова.
4. Тренажёр 4 — цифры и предложения.
5. Тренажёр 5 — заполнение бланков.

Листы можно печатать сколько угодно раз. Лучше заниматься по 15–20 минут каждый день.

---

Папка `scripts/` — генератор файлов (Python + Node.js), для занятий она не нужна.
